This repository contains the exploratory data analyses for machine learning pipelines critiqued in the Master's Thesis "A Framework Assessing the Alignment of a Machine Learning Algorithm's Feature Importance Metrics and Data Behavior in Chemistry".

For Cases 1 and 2, the ZIP file also has the feature importance metrics for the algorithms used in each case.

For Case 5, the EDA and the results for machine learning are in a Jupyter notebook (.IPYNB file) the first thing you get to this repository.
